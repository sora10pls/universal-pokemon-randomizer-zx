# Universal Pokémon Randomizer ZX

## Info
This project is based on Universal Pokémon Randomizer ZX and intends to add support for the Pokémon expansion mod for Pokémon Ultra Sun and Pokémon Ultra Moon.

## Setting Up
* Dump and unpack a ROM of Pokémon Ultra Sun or Pokémon Ultra Moon (Ver. 1.0).
* Replace the contents of the unpacked RomFS and ExeFS with those from the expansion mod.
* Rebuild a new ROM with these modified contents, preferably in `.3ds` or `.cxi` format.
* Run the tool as you normally would, and generate a new `.cxi` file or a LayeredFS patch to play your randomizer.

## Building
To build this project, refer to the [guide](https://github.com/Ajarmar/universal-pokemon-randomizer-zx/wiki/Building-Universal-Pokemon-Randomizer-ZX) on the original repo's Wiki.

## Disclaimer
This build of the program is entirely designed to be used specifically with the Pokémon expansion mod. As such, any side effects that negatively impact randomization for other games that are not Pokémon Ultra Sun or Pokémon Ultra Moon will not be fixed. If you wish to randomize those games, you should not be using this fork.
